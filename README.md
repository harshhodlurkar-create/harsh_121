# Intelligent Transaction Banking System

A banking application with rule-based fraud detection.

## Tech stack
- Backend: Java, Spring Boot, Spring Data JPA, Spring Security, MySQL
- Frontend: Angular

## Features
- User registration and login with hashed passwords
- Bank accounts: deposit, withdraw and transfer
- Fraud detection rules: large amount, rapid transactions, unusual hours
- Admin review: approve or block flagged transactions

## Folders
- backend: Spring Boot REST API
- frontend: Angular application
